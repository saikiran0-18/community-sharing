# ToolShare - Community Tool Sharing System

ToolShare is a web-based community tool sharing platform where users can borrow and lend tools within their local area. The main aim of this project is to reduce unnecessary tool purchases by allowing people to share tools safely and easily.

## Project Features

- User registration and login
- Borrower and owner roles
- Borrower can create tool requests
- Owner can accept or reject requests
- Payment and security deposit support
- Tool condition verification
- Request status tracking
- Screenshots and project PPT included

## Tech Stack

### Frontend

- JavaScript

### Backend
- Node.js
- Express.js

- backend - contains backend code

Frontend deployed on Render  
Backend deployed on Vercel  
Database connected using MongoDB Atlas

## Conclusion

ToolShare provides a simple and useful platform for sharing tools in a local community. It helps users save money, reduce unused tools, and make borrowing and lending more organized.
